# Rock Paper Scissors Lizard Spock 🎮

Interactive Python terminal game based on the popular "Rock Paper Scissors Lizard Spock" variation.

## Features
- Play against the computer 🤖
- Random CPU choices using Python's random module
- Emoji-based interface ✊ ✋ ✌️ 🦎 🖖
- Win, lose, and tie outcomes
- Input validation

## Concepts Used
- while loops
- if-elif-else statements
- random module
- user input
- conditional logic

## How to Run

```bash
python rpsls_game.py
```

## Game Choices

1. ✊ Rock  
2. ✋ Paper  
3. ✌️ Scissors  
4. 🦎 Lizard  
5. 🖖 Spock
